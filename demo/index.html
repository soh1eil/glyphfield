Persian and Arabic, shaped by the browser.

Glyphs are drawn by your browser's own canvas text engine, so joining, ligatures and right-to-left order are exactly what the platform does. glyphfield only samples the result. Type anything.

Well behaved

Pauses when the tab is hidden or the canvas scrolls offscreen, honours prefers-reduced-motion by snapping instead of flying, handles resize and devicePixelRatio, and degrades from WebGL to 2D canvas to an accessible label.

Tiny and testable

One ES module, no build step, no dependencies. The sampling math, spring physics and word scheduler are pure functions with tests that run under node --test.

Three lines to alive.

Drop in one file. Give it a canvas that has a size.

import glyphfield from './glyphfield.min.js';

const f = glyphfield(canvas, {
  colors: ['#7c8cff', '#4fe0d0', '#ffd479'],
  lens: { alt: { 'Hello': 'سلام', 'سلام': 'Hello' } }
});
f.cycle(['Hello', 'سلام', 'مرحبا'], 3800);
f.scatter(0.4);   // 0 assembled … 1 dispersed
